# 分阶段用户引导

每个用户可感知阶段都给“当前结果/阻塞＋下一步＋执行者”。按实际结果自然表达，不强制每条使用相同标题。需要用户行动时给一个清楚的当前操作；助手可继续时说明后直接执行。工具next_action、退出码、路径或任务ID是判断依据，不是面向用户的完整引导。

| 阶段/分支 | 应向用户说明 | 下一步与执行者 |
| --- | --- | --- |
| 收到制作需求 | 已收到的链接、市场与制作范围，缺少的关键项 | 信息齐全由助手检查连接并解析；缺市场/链接等只补问缺项，已有信息不重复询问 |
| 缺Key或配置失败 | 缺配置还是具体错误、当前环境和已知保存位置 | 介绍三种配置方式并按配置合同给真实入口或完整命令；明确用户点击/输入/选择后助手将按同路径核验，已有可用输入与权限则由助手代配继续 |
| 身份与能力核验 | 已连接账号和当前能否执行所需阶段 | 具备能力由助手继续解析，用户暂无需操作；能力缺失说明被阻塞的阶段与需恢复的服务能力，保留资料，不让用户重复注册或重建Key |
| 商品解析受理/等待 | 已受理仍在解析，尚未取得完整结果 | 助手按建议间隔查询原任务，用户无需重复提交；无法继续等待时交代恢复方式 |
| 取得商品并展示原图 | 商品事实、用户可查看的真实图片、已确定或待确定变体 | 单条先实际出图。变体明确则助手继续分镜；确需选择时让用户回复已展示图号/颜色，收到后再使用对应原图，不为每张图新增审批 |
| 分镜、口播与素材策略 | 当前创意方案及原图直用/补图理由 | 无费用步骤由助手继续准备正式报价；若要付费补图，先取得本阶段正式报价并按费用规则确认，不假装视频正式总价已知 |
| 正式报价就绪 | 按主SKILL展示最终选图、分镜/口播、规格、金额、已消费及可查余额 | 无匹配授权时给可直接回复的明确确认句，或让用户说明修改项；已有覆盖输入与金额的授权则告知沿用后由助手提交，不再等待重复同意 |
| 已提交/生成等待 | 任务实际受理与状态，冻结不等于消费；不编造百分比或ETA | 助手查询同一任务，用户无需重交链接/再次付款。当前等待窗口结束时保存恢复点，说明用户可回复“继续查询这条视频”，由助手续查原任务，不新生成 |
| 缺资料、无法看图/展示、失败或结果未知 | 具体缺项/限制、哪些步骤未执行或已发生、可核验费用 | 给用户可完成的补充或选择动作；助手能恢复则查询原任务/刷新原媒体。未知结果先核查，无法展示商品图暂停单条后续准备；不以“继续”暗中授权新付费任务 |
| 余额不足/充值后 | 正式所需、可查余额及差额；不可查时如实说明 | 用户从已核验个人账户入口自行充值，完成后可回复“已充值”；助手再核身份、到账、原任务和报价，不能把用户回复当到账事实或扩大原授权 |
| 生成成功、下载失败或账务未终结 | 分开说明生成、交付、内容核验与账务状态 | 助手重试原产物下载/核账，用户无需再次生成；确需用户接收附件或处理权限时给具体操作。等待结束同样交代原任务恢复方式 |
| 单条交付完成 | 实际预览/下载入口、保存位置（可达时）、费用和仍未核验项 | 用户可查看或下载；全部完成则明确无需其他必做操作，不要求用户再回复“确认完成”。用户提出修改后再评估新输入和费用，不默认重做 |
| 批次执行/暂停/完成 | 已处理数/总数、当前行、成功/失败/等待、累计可核验费用 | 在既有批次授权内由助手继续下一行，可合并简短进度，不每行索要确认。超预算、输入变化或阻塞时明确暂停范围与所需选择；完成给逐行结果及汇总，回写失败单独说明 |

给用户的链接、命令、图号和确认内容须来自本次真实结果，不能直接发送未填占位或示例价格。用户明确要求少打扰时合并自动步骤的更新，仍须交代人工操作点、消费授权、阻塞和最终交付；不因此跳过单条首次出图。用户明确停止时停止新提交并说明已受理任务的已知状态，不承诺后台取消。

## 简短话术的使用方式

- 助手继续：“商品信息和图1已展示，黑色款已确定。接下来我会整理马来语分镜并查询正式报价，你暂时无需操作。”这句话必须在实际出图后使用。
- 用户选择：“两种颜色尚未确定，请回复已展示的图1或图2。收到后我会用对应颜色准备脚本和报价。”不能对已明确的变体重复提问。
- 用户授权：“本次所选图、剧本和正式报价见上方；尚未提交。可以回复按此方案生成并明确本次数量与金额上限，或告诉我需要改哪一项。”实际发送时替换为本次具体数量与正式金额，不能让用户自己补完整授权书。
- 等待续接：“任务仍在处理中，本次查询先结束。稍后回复继续查询这条视频，我会沿用原任务核查，不会重新生成。”只有当前确实无法继续等待时使用，不把会话恢复说成已安排自动调度。

以上是离线表达示意，不证明图片已显示、任务已执行或费用已授权。实际回复可合并措辞，但不能遗漏当前该谁做什么。

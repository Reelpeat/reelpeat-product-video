# 电商创作：从商品事实到可执行 prompt

在商品事实和对应图片已能核验后使用。剧本、卖点选择与视觉决策由宿主完成；不能把创作推断写成商品事实。Reelpeat 为产品，Mint 为公司。

## 先确定卖点，而不是堆砌功能

对关键素材在当前对话或非秘密创作记录中保留简短依据：事实字段/图片 → 能说什么 → 不能据此推出什么。

| 可核验材料 | 可用表达 | 不可推断 |
| --- | --- | --- |
| 详情写有 350 ml，图片能看清杯体 | 350 ml 容量；近景展示杯身 | 保温 24 小时、防漏、食品认证 |
| 图片能看见拉链与独立小袋 | 展示拉链和收纳分区 | 装得下具体型号电脑、防盗、防水 |
| 来源仅有“畅销”营销文案 | 标注来源说法，通常不选作主卖点 | 销量第一、真实用户好评率 |

选择一个最容易被画面证明、与目标人群使用情境相关的主卖点，辅助卖点至多两个。优先“把拉链拉开，展示分区”这样的视觉动作。画面无法证明的效果、疗效、前后对比、极限承重、耐用性不可通过生成画面当作实测证明。

市场和语言影响使用场景、口播与行动引导，不改变商品的实际功能。尊重已知价格/币种/时效；没有当前价格和促销依据时不写折扣倒计时，不生成假评价和假认证。

## 一个短创意，少量镜头

先在内部整理下面五项；对用户只展示足以理解方案和费用的摘要，不强迫填写表单：

1. 确定商品/变体、目标市场/语言/人群、实际可用规格。
2. 一条主卖点及证据，必要的辅助卖点。
3. 开场具体画面、镜头动作与节奏。
4. 原图直用或补图的理由、已检查的图片引用和顺序。
5. 最终 prompt 与完整生成参数。

15 秒常用结构如下，可按商品和用户要求调整：

| 时间 | 目的 | 可执行画面 |
| --- | --- | --- |
| 0–3 秒 | 快速辨认商品和使用情境 | 一个具体动作或商品特写，不做无关炫技 |
| 3–8 秒 | 展示主卖点 | 一个连续动作，给足看到结构细节的时间 |
| 8–12 秒 | 补充一处细节/生活场景 | 同一款、同一颜色、同一人物/场景关系 |
| 12–15 秒 | 商品定格和行动引导 | 留出稳定构图；不用无依据促销 |

只有 4–6 秒时，收敛为一个动作加短定格，不塞四段镜头。多镜头只是同一次视频生成的叙事指导，不承诺模型逐秒精确遵守或额外提供剪辑服务。文字/口播越短越容易执行；精确字幕、包装小字和长台词不能作必达保证。

## 选图与是否生图

| 原素材情况 | 选择 |
| --- | --- |
| 商品清楚、角度足够，脚本可通过近景和适度运镜表达 | 原图直用，生图费用为零 |
| 需要人物持物、使用场景或统一构图，真实商品参考足够 | 最少量补图，先说明目的与费用 |
| 不知具体变体、关键结构被遮挡、只有文字没有可看图 | 先补资料，不靠生成图补事实 |
| 图已能用，仅想“更高级” | 优先优化构图/动作/光线提示词，避免无目的增加消费 |

只使用实际检查过的同款图片。不为凑数量使用不相干角度/变体。生成图重新核对：外形、颜色、比例、包装、Logo、手与商品接触点；错误图不继续进入视频，不自动重试收费。

## 电商 prompt 的具体约束

将参考图与角色说明按已选 `asset_ref` 顺序对应描述，例如“第一张参考图定义商品外观，第二张定义使用情境”。不要发明供应商专用标记或把 OSS Key 填入提示词。

推荐按以下信息组织自然语言 prompt；按任务取舍，不要求重复模板标题：

- **商品锁定：**保持参考商品的轮廓、款式、颜色、材质、比例、包装与可见标识；跨镜头保持同一件商品，不凭空增减按钮、配件或图案。
- **场景与动作：**地点、商品的位置、一个主要动作、镜头何时看清关键细节。只有事实支持的使用方式才示范，不演示未知的开合结构。
- **人物与持物：**只有创意需要才出现人物。真实皮肤纹理、自然表情、手部结构合理；手与商品有稳定接触、遮挡和尺度关系，商品不穿模、不悬浮、不变尺寸。
- **摄影与连续性：**明确景别、适度运镜、自然光线与焦点；保持方向、背景、商品状态连续。避免多个冲突镜头指令和无法完成的同时动作。
- **文案与声音：**目标语言、简短口播/意图、已知事实；音频是否开启与参数一致。关闭音频时不依赖口播传递唯一卖点。
- **负面约束：**选与商品有关的少量限制，如不变色、不增配件、不改 Logo、不增加假字幕和伪认证。负面词不能保证模型绝对遵守。

### 示例：用户确认的深蓝色 350 ml 杯子

前提是图片确实可看、杯体颜色与容量有来源依据；未确认保温、防漏或旋盖结构。以下是创作示例，不是可提交价格或商品事实。

**方案摘要：**面向通勤场景，展示深蓝色杯体与简洁外观；原图已清楚，不补图。15 秒内用桌面取杯、杯身细节、手持定格三个画面，不拍未知开盖方式。

**视频 prompt 示例：**

> 竖屏生活方式商品短片，参考图定义同一只深蓝色杯子的外观和比例。早晨自然窗光下，杯子放在整洁桌面；手从画面侧面自然拿起杯子，保持手指与杯体接触合理、商品大小不变。切到杯身近景，用缓慢横移展示颜色与轮廓，再回到自然手持构图，最后稳定定格。人物如出现只作生活场景陪衬，肤质自然、动作克制。所有镜头保持同款同色同包装，不新增部件，不改变可见标识，不生成未经证实的防漏、保温或认证画面。文案围绕已确认的 350 ml 容量和通勤携带情境，短句，不加入促销价格；不依赖模型精确排版小字。

若原图只有杯子，用户明确要求人物持杯场景而原图无法支撑，可先做一张参考场景图：保留同一杯体，让一只自然的手在正常尺度下稳固握杯，窗边中景、简洁背景，不添加新功能或结构。获得图片正式报价与授权后才生图。

## 交付时检查什么

能查看实际视频时，核对商品/变体、人物持物、动作、严重变形、文案事实和音画；按工具或实际媒体信息核对时长、比例、分辨率。不能查看则明确未验内容；请求规格与实际规格分开说明，不能只凭请求参数说产物已达标。

发现问题时解释具体镜头和已消费费用，给一个最小改动建议；新一轮付费生成须重新准备/报价/授权。首版不引入自动评分、无限优化或复杂精品 Agent 工作流。
